# ReelsMaker

Локальная монтажная для коротких вертикальных роликов (Reels, Shorts, TikTok). Вы снимаете «говорящую голову» со звуком,
по желанию — общий план и запись экрана. ReelsMaker расшифровывает речь, режет её на реплики, и **агент-монтажёр**
(Claude Code) собирает из одного сюжета **несколько разных вариантов** ролика 1080×1920: с другим хуком, другим набором и
порядком реплик, перебивками общим планом и вставками экрана. Субтитры, заголовок и охранная зона площадки — автоматически.

Всё работает на вашем компьютере: ffmpeg, видеокарта (NVENC) или процессор, локальная расшифровка faster-whisper.
Публикации нет — готовые ролики вы выкладываете сами.

## Что умеет

- **Сюжет из исходников.** Основа (крупный план, единственный звук), общий план для перебивок, один или несколько
  скринкастов. Роли угадываются по именам файлов или задаются в интерфейсе.
- **Реплики.** Речь основы расшифровывается со временем каждого слова и режется на реплики по концу фраз и паузам.
- **Агент-монтажёр** в окне каждого сюжета: изучает кадры и реплики, выкидывает оговорки и дубли, пишет монтажный лист,
  проверяет его, собирает ролики, смотрит контактные листы и докладывает. Работает через Claude Code по вашей подписке.
- **Несколько вариантов из одного сюжета** — сколько скажете. Различаются хуком, первыми секундами, набором реплик и
  видами (крупный, общий, экран): площадки понижают почти-дубли.
- **Кроп каждого исходника** в интерфейсе — рамка поверх кадра, пропорции 9:16 и другие.
- **Оформление из интерфейса:** шрифт, размер, цвет и обводка заголовка, субтитров и плашек; свои шрифты загружаются
  файлом. Одно оформление на все варианты.
- **Охранная зона Reels** (сверху 220, снизу 450, по бокам 35 px): текст и вставки экрана не уходят под интерфейс
  площадки, субтитры стоят на уровне груди, а не на лице, всегда одной строкой.
- **Живой интерфейс:** прогресс сборки и работы агента, обложки, контактные листы, плеер.

## Требования

- **Windows 10/11** — запуск ярлыком и окно-приложение Chrome. Сам сервер на Node работает и в других ОС, но
  проверялся только на Windows.
- **Node.js ≥ 22.13** и **ffmpeg** с ffprobe (в PATH или путь в `.env`).
- Видеокарта **NVIDIA** — по желанию: кодирование `h264_nvenc` и быстрая расшифровка. Без неё — `libx264` на процессоре.
- **Python с faster-whisper** — для расшифровки (без неё ролики соберутся без субтитров). См. «Расшифровка».
- **Claude Code** с входом по подписке — для агента-монтажёра. Монтажный лист можно писать и вручную.

## Установка и запуск

```bash
git clone https://github.com/semakin1306-dev/reelsmaker.git
cd reelsmaker
npm ci
copy .env.example .env      # и заполнить, см. «Настройка»
npm test                    # по желанию: тесты
npm run ui -- --open        # сервер + окно-приложение Chrome на http://127.0.0.1:8787
```

Или двойной щелчок по `ReelsMaker.bat`: сервер стартует скрыто (журнал — `<RF_DATA_DIR>/ui.log`), окно открывается
отдельным лёгким профилем Chrome, повторный запуск не плодит окна. `DATA` в начале `.bat` должна совпадать с
`RF_DATA_DIR`. Ярлык на рабочий стол — на `ReelsMaker.bat` со значком `desktop/reelsmaker.ico`.

Если перед открытием нужно что-то своё (например, поднять прокси), положите рядом `local-start.bat` — он вызывается
при запуске и в git не идёт.

## Как снять и собрать ролик

1. **Папка сюжета** в папке входа (`<RF_DATA_DIR>/inbox/<сюжет>/`), в ней видео:
   - `голова.mov` — вы говорите в камеру (основа, звук только отсюда);
   - `дальний.mov` — общий план для перебивок (по желанию), сверху в кадре удобно оставить место под экран;
   - `экран — панель.mp4`, `экран — гитхаб.mp4` — записи экрана (по желанию, сколько угодно; подпись после «экран —»
     помогает агенту выбрать нужный);
   - `озвучка.wav` (любой аудиофайл) — отдельная запись голоса: **заменяет звук основы** (запись — кнопка с микрофоном
     на странице, дублей может быть несколько; см. «Озвучка отдельным файлом»).

   Имена не обязательны: роли (основа, дальний, скринкаст) выбираются в таблице «Исходники».
2. **Расшифровка** — кнопкой «Расшифровать основу» (или сама при сборке). Реплики r01, r02… появятся в таблице.
3. **Кроп** — ссылка «кроп» у каждого исходника: уберите лишнее из кадра.
4. **Оформление** — кнопка в шапке: шрифты, размеры, цвета. Образец показывает текст в масштабе кадра с охранной зоной.
5. **Сколько роликов** — поле «Вариантов в итоге».
6. **Агенту** — в окне справа, например: «Посмотри исходники и собери 5 разных вариантов по 30–60 секунд, экран
   вставляй там, где я говорю про интерфейс». Он сам составит лист, проверит, соберёт и доложит. Над сюжетом видно,
   на каком он этапе.
7. **Ролики** — внизу страницы: обложки, плеер, контактный лист, скачать. Сменили кроп или оформление —
   «Пересобрать все варианты»; галочками в таблице листа можно собрать только часть.

Готовое лежит в `<RF_DATA_DIR>/out/<сюжет>/<дата_время>/`: `<сюжет>_vNN.mp4` для выкладки, в `vNN/` — обложка, контактный
лист, схема монтажа `plan.json` и журнал ffmpeg. Каждая сборка — новая папка, прежние не затираются.

Подробно, как всё устроено внутри, — [docs/HOW-IT-WORKS.md](docs/HOW-IT-WORKS.md).

## Озвучка отдельным файлом и очистка звука

Видео может быть без звука (или со звуком, который не нужен): голос записывают отдельно, видеоряд остаётся тем же.

- **Запись.** На странице сюжета кнопка «Записать озвучку»: выбор микрофона, запись без потерь (24 бит, 48 кГц).
  Каждая запись — новый файл (`озвучка.wav`, `озвучка 2.wav`…), прежние не затираются; их может быть несколько
  (дубли или части). Можно просто положить аудиофайл в папку сюжета. «Удалить» убирает запись в `<сюжет>/.rm/trash`,
  не стирая её.
- **В монтаже.** Звук и субтитры идут с озвучки, а основа, дальний план и скринкаст дают только картинку. Озвучка
  режется на реплики с буквой файла (`a01`, `b01`…); в листе сегмент выглядит как `{ "voice": "b03" }`, агент сам
  выбирает лучший дубль каждой фразы.
- **Звук видео не нужен** — галочка «Звук видео не использовать» (или `rm mute on`): без озвучки ролики собираются без
  звука и без субтитров, пока вы не запишете голос.
- **Очистка.** Каждая озвучка получает «чистую» копию (`.rm/clean/`, оригинал не меняется): режекторы на кратных
  1 кГц (помехи шины USB дают писк и дребезжание; частоты подобраны под Behringer C-1U, список — `COMB_KHZ` в
  `voice-clean.ts`), шумоподавление по образцу шума, гейт, выравнивание громкости. Образец шума — тишина в начале
  записи, поэтому после «Записать» первые 1,5 секунды молчите (страница подсказывает); нет тишины — берётся образец
  прошлой записи этого микрофона. Галочка «Очищать озвучку» (`voiceClean` в `story.json`) отключает очистку.

## Виртуальный микрофон (Windows, значок в трее)

Та же очистка на лету для любых программ (Telegram, OBS, браузер): настоящий микрофон → ffmpeg с цепочкой →
виртуальный кабель VB-Cable; в программе микрофоном выбирают «CABLE Output». Задержка около 150–200 мс: для голосовых
и записи нормально, для звонков заметно.

1. `pip install -r apps/mic-clean/requirements.txt`; драйвер [VB-Cable](https://vb-audio.com/Cable/) (бесплатный,
   нужны права администратора и перезагрузка).
2. Запуск — `MicClean.bat` (значок микрофона в трее). Меню значка: «Очистка голоса» (выкл — звук как есть, для
   звонков), «Выучить шум микрофона» (4 секунды тишины), «Запускать вместе с Windows», лог, выход.
3. Настройки — `<RF_DATA_DIR>/micclean.json`: `input` (имя микрофона в DirectShow, список — `ffmpeg -list_devices true
   -f dshow -i dummy`; по умолчанию `Микрофон (2- C-1U)` — **поменяйте на свой**), `output`, `gainDb`, `processing`.

## Настройка (`.env`)

Скопируйте `.env.example` в `.env`. При ошибке сервер перечисляет все неверные поля сразу.

| Переменная | Что | По умолчанию |
|---|---|---|
| `RF_DATA_DIR` | папка данных — **обязательно** | — |
| `RF_INBOX_DIR` | папка входа (папки сюжетов) | `<RF_DATA_DIR>/inbox` |
| `RF_OUTPUT_DIR` | папка готовых роликов | `<RF_DATA_DIR>/out` |
| `RF_FFMPEG_PATH`, `RF_FFPROBE_PATH` | пути к программам | `ffmpeg`, `ffprobe` из PATH |
| `RF_STT_PYTHON` | Python окружения с faster-whisper | не задан — без расшифровки |
| `RF_STT_MODEL` | каталог модели faster-whisper | не задан |
| `RF_HW` | кодировщик: `nvenc` (NVIDIA) или `cpu` (libx264) | `cpu` |
| `RF_HUB_URL` | адрес интерфейса | `http://127.0.0.1:8787` |
| `RF_AGENT_PROXY` | HTTP(S)-прокси агента к Anthropic | напрямую |
| `RF_TIMEZONE` | часовой пояс для показа времени | `Europe/Moscow` |

В папке данных ReelsMaker хранит ещё оформление (`style.json`), свои шрифты (`fonts/`) и профиль окна (`.browser/`).

## Расшифровка

Нужен Python 3.10+ с [faster-whisper](https://github.com/SYSTRAN/faster-whisper) и модель в формате CTranslate2.
Проверено с `faster-whisper-large-v3-turbo` на GTX 1660 Super (около 1 ГБ видеопамяти, 8 минут речи — за полторы минуты).

```bash
python -m venv C:/stt/.venv
C:/stt/.venv/Scripts/pip install faster-whisper nvidia-cublas-cu12 nvidia-cudnn-cu12
# модель, например: huggingface-cli download mobiuslabsgmbh/faster-whisper-large-v3-turbo --local-dir C:/stt/turbo
```

В `.env`: `RF_STT_PYTHON=C:/stt/.venv/Scripts/python.exe`, `RF_STT_MODEL=C:/stt/turbo`. Модель поднимается отдельным
процессом только на время расшифровки и сразу выгружается; сеть при этом не нужна (`HF_HUB_OFFLINE=1`). Расшифровка
лежит рядом с видео: `голова.transcript.json` (слова с таймкодами); пересняли видео — она пересчитается.

## Агент-монтажёр

Агент — это Claude Code без окна: ReelsMaker находит `claude.exe` из расширения Claude Code для VS Code (или `claude` в
PATH) и общается с ним по протоколу stream-json. Авторизация — ваш вход в Claude Code, API-ключ не нужен. Модель
выбирается над чатом. Сессия сюжета продолжается после перезапуска, «новая» начинает беседу заново.

Без вопроса агент читает файлы, правит только `edit.json` и `story.json` в папке сюжета и запускает команду `rm`
(API сюжета). Всё остальное приходит карточкой «Разрешить / Запретить».

В листе у каждой сцены можно записать подпись `note` (какие реплики и что на экране): на странице у варианта
раскрывается «план по сценам» с временем, репликой, картинкой и подписью. Проверка листа предупреждает, если кадр
держится меньше 2,5 с и картинка будет скакать.

## Разработка

```bash
npm test             # тесты всех пакетов (node:test)
npm run typecheck    # проверка типов
```

TypeScript без сборки (`node --import tsx`), npm workspaces: `packages/core` (конфиг, запуск программ, SQLite),
`apps/pc-agent` (сюжет, ffprobe, расшифровка), `workers/render` (монтаж, ffmpeg, субтитры, шрифты), `apps/hub`
(сервер, страница, агент, команда `rm`).
